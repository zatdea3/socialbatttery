이 브라우저에 저장되는 정보

닉네임, 처음 방문한 날짜, 오늘의 답변과 진행 상태, 현재 주기의 최대 7일 결과를 브라우저 저장소(localStorage)에 저장해요. 계정 가입은 없고 이 데이터의 서버 전송 기능은 넣지 않았어요. 현재 답변은 날짜가 바뀌면 초기화되고, 7개 기록을 채우면 다음 기록부터 새 주기로 바뀌어요. 닉네임과 방문 기준일은 기록 삭제 또는 브라우저 데이터 삭제 전까지 남아요.

결과를 공유할 때

공유 기능을 직접 누르면 닉네임·배터리 퍼센트·결과 날짜가 공유 문구 또는 링크의 # 뒤에 포함돼요. 링크를 받은 사람은 이 내용을 볼 수 있어요. 결과 이미지를 저장하거나 보내도 같은 정보가 표시돼요. 개별 답변과 내 기록 그래프는 공유 링크에 넣지 않아요. 공유 링크의 내용은 브라우저 주소의 일부이며 암호화된 비밀 정보가 아니에요.

접속 기록과 광고

사이트를 공개하면 호스팅 제공자가 서비스 제공과 보안을 위해 IP 주소, 브라우저 정보, 요청 시각 등 접속 기록을 처리할 수 있어요. 보관 기간과 구체적인 처리는 실제 사용하는 호스팅 서비스 정책을 확인해주세요.

Google AdSense 광고가 활성화된 경우 Google 및 제3자 광고 제공자가 광고 제공·측정·부정 사용 방지 등을 위해 쿠키, 웹 비콘, IP 주소와 기기 식별자 등의 정보를 처리할 수 있어요. 제3자가 브라우저에 쿠키를 저장하거나 읽을 수 있어요. 닉네임·개별 답변·배터리 점수를 광고 코드의 맞춤 타기팅 값으로 전달하지 않아요. 광고 관련 처리는 Google 파트너 사이트 정보 이용 안내와 광고 설정을 참고해주세요. 필요한 지역별 동의는 사이트에서 제공하는 동의 메시지로 관리해요.

저장 정보 삭제

아래 버튼 또는 브라우저의 사이트 데이터 삭제 기능으로 이 기기에 저장된 테스트 정보를 지울 수 있어요. 이미 다른 사람에게 보낸 링크나 이미지는 별도로 삭제해야 해요. 테스트 기록 삭제 버튼은 제3자 광고 쿠키나 호스팅 접속 로그를 삭제하지 않아요.

테스트 화면의 개인정보 안내에서 기록을 삭제할 수 있어요.
